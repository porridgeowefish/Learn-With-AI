Learn-With-AI 是一个学习工作台。你可以把资料、问题、笔记和练习留在同一个项目里，让 AI 帮你理解难点，再检查自己是否真的学会了。

## 第一次使用：走一遍完整学习流程

1. **选好模型。** 登录后可用系统模型，余额和签到在「设置 → 个人信息」查看。你也可以在「模型连接」填自己的 API Key，或连接已有 ChatGPT 账号。配置自己的连接不需要登录 Learn-With-AI。
2. **选一个具体问题。** 从侧栏打开「学习的方法论」，或者新建项目并导入要读的资料。试着问：「我能算出导数，但不理解它为什么表示变化率，能用一个例子讲吗？」
3. **边读边追问。** 在「资料」打开原文，在「教师」继续讨论。看到难懂的一段，可以圈出或引用后再问；在复习稿中也可以选中文字打开 Ask AI。
4. **合上资料，做一道练习。** 打开「笔记与复习」，从「练习」开始，先独立回答，再看反馈。把仍不确定的点带回教师对话。
5. **讲给教师听。** 用自己的话解释「导数为什么表示变化率」，让教师提问。能回答反例、说清适用条件，通常比能复述定义更有用。

## 工作区里有什么

| 功能 | 什么时候用 |
| --- | --- |
| 学科地图 | 还不知道从哪里开始时，用主题与先修关系规划顺序。可以为不同主题建立各自的学习项目。 |
| 资料与教师 | 读书、看文档或学概念时，把资料和问题放在同一项目。教师可以按主题讲解、讨论或带你读书。 |
| 复习稿 | 学完一段后，把要点整理成下次能读懂的稿件。可以自己编辑，也能用 Ask AI 追问。 |
| 练习 | 用题目暴露知识盲区，做完看反馈，再回去补薄弱环节。 |
| 笔记 | 留下关键结论、反例和还没想通的问题。可在设置中调整教师自动笔记。 |
| 讲给教师听 | 把 AI 当成听众，试着讲清来龙去脉，并根据追问补足解释。 |
| 收藏 | 查看学习过程中发现的宝物，也可回到对应的学习记录。 |

## 让工作台适合你

- **学习偏好**：写下长期偏好，例如「先给例子，再给定义」。只对当前讨论有效的要求，可写在对应对话中。
- **回复、搜索与记忆**：选择回复方式、是否联网搜索，以及如何使用学习记忆。教师用到的在线资料，仍建议回看原文。
- **模型连接**：选好默认学习模型；需要时，可在高级设置里为复习稿、练习等单独指定连接。
- **存储与数据**：在这里查看或迁移本地工作区。切换工作区前，先确认当前资料和对话所在位置。

可以用上方的「开始屏幕向导」跟着界面操作。第一次学习不妨先完成一个小问题，留下一条自己的解释，再继续扩大学习范围。
