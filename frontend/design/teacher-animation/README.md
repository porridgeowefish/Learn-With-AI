## 当前方向：无文字表情

用户已取消书本、写字和手部运动。当前素材在 `frontend/design/teacher-animation/archive/teachers/expressions/`，预览入口为其中 `index.html`。每角色四种表情：思考、灵感、讲解、开心。原生imagegen将手与整个角色一起绘制，没有肢体拆层。图中没有文字或标签底色，只有思考状态的问号。`expressions.py` 归一化整只角色尺寸，只为问号制作弹出和淡出；手和身体在此动作中逐像素不变。

`*-thinking.gif` 为2秒问号动效；`*-expressions.gif` 为8秒四表情切换后停止；四个独立状态PNG可直接选用。预览默认静态，点击思考或播放按钮才弹出问号。原始整张表情图保留为 `*-sheet.png`。生成提示为：保持教师衣帽和萌系比例，手自然贴在身侧、与身体一体绘制；四种表情、无书无笔、无文字无标签，第一张脑袋右上角单独放一个小问号。

| 时间 | 动作 |
| --- | --- |
| 0–2 秒 | 手横向移动，身体轻侧倾 |
| 2–3 秒 | 完全静止 |
| 3–6 秒 | 取笔、从左到右写两行、放下笔 |
| 6–7 秒 | 完全静止 |
| 7–9 秒 | 手指向笔记，身体轻倾后归位 |
| 结束 | 停在最后画面，不循环 |

`render.py` 使用现有 Pillow 与 numpy，输出 480×480、运动段50fps、名义时长9秒的 GIF。静止帧合并成持续时长，最终编码350帧。没有光流补帧、帧间淡化或重复生成不同角色图。浏览器可能因解码和刷新调度延长 GIF 的实际播放时间；预览页在9秒后显式切换到最终PNG，保证页面停止。
