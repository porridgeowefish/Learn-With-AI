# 前端设计预览

页面来自产品的 React 入口。Vite 配置只替换启动顺序。浏览器加载模拟数据后，渲染产品的 AppShell 和实际页面。开发时修改组件或样式即可看到效果。安装包的入口不加载模拟数据。

## 使用与保存

- 仓库根运行 npm run design，打开 http://127.0.0.1:5188/settings。侧栏可进入其他页面。
- 样例保存在此预览地址的 IndexedDB。刷新和重开保留修改。使用新的浏览器配置可从初始样例开始。
- 项目变更、聊天回复、模型连接、文件与学习任务都是设计数据。预览不会移动真实工作区，不访问 AI 服务。桌面框选使用标记为示例的图片。文件夹选择仅使用显示名称。预览 ZIP 与正式学习记录包采用独立格式，使用本预览导出的 ZIP 体验导入。
- npm run design:build 生成独立静态站点。使用 npm run design:serve 在同一专用端口查看构建结果。
- 产品新增页面时使用实际路由。新增接口要在对应模块实现模拟行为，并从正常页面验证。npm run design:check 对照产品路由和接口路径。新增或删除路径会要求复核。
- 调整已确认的交互时，在下表追加新决定并注明替代关系。浏览器里的演示数据和界面设计决策分开保存。
