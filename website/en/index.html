Your first session

Try an example.
Then bring your materials.

Learn-With-AI is desktop learning software maintained by porridgeowefish on GitHub under the MIT license.

  1. Download for your system

    Choose Windows, macOS or Linux on GitHub Releases, with the matching x64 or ARM64 architecture.

  2. Open the bundled example

    Select 体验示例 to explore preset explanations, notes, review and quizzes without a key. Example data resets when closed.

  3. Connect your model

    Add an OpenAI- or Anthropic-compatible API in Settings (设置), then create a learning unit or subject map and import your materials.

Before you start

Your files, your model connection.

Does local-first mean fully offline AI?

Projects, conversations, materials and notes stay on your computer. Local parsing and local OCR do not need document uploads. Tutoring, Ask AI, generation and optional cloud recognition send necessary content to your configured services. Local-first does not mean model generation is offline.

Is it free?

The project is open source under MIT. The bundled example needs no API key. Generating your own content needs a working model connection, and your chosen provider may charge for usage. Free model credits are not included.

Is this a course about AI?

This is an app for learning different subjects with AI, rather than an AI course collection. Use your own questions and materials to study mathematics, automatic control or another subject.

Where are the source, installation guide and updates?

The official Learn-With-AI GitHub repository has the source and English guide. Find versions in Releases and report problems in Issues. The repository was formerly named LLL_life_long_learn; old repository links redirect to the current project.
