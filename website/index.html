一次完整的学习过程

让每一步理解，都有下一步。

01 / 找到起点

把教材变成学习地图

从一个问题或一门学科开始，也可以导入 PDF、讲义或幻灯片。查看主题之间的关系、先修知识和优先级。

02 / 看懂概念

追问、换例子、看图解

AI 教师可以用文字、公式、表格、SVG 和交互演示解释概念。把有用的讲解留在笔记与复习稿中。

03 / 检验理解

先做题，再试着教会它

作答后检查答案与解析。讲给教师听，让它从新手视角追问，找出自己还没说清楚的地方。

以上均为人工编排的产品演示。实际模型输出取决于模型和提问；重要概念、答案和 OCR 结果需对照原文核验。

第一次打开

先体验，再带上
自己的学习材料。

Learn-With-AI 是桌面学习软件，源码由 porridgeowefish 在 GitHub 维护，以 MIT 许可开源。

  1. 下载对应系统的安装包

    前往 GitHub Releases，选择 Windows、macOS 或 Linux，以及 x64 / ARM64 架构。

  2. 打开「体验示例」

    不需要 Key，先体验预置讲解、笔记、复习和练习交互。示例关闭后重置。

  3. 连接模型，创建自己的内容

    在设置中添加 OpenAI 或 Anthropic 兼容 API，然后从问题、学科或自己的资料开始。

使用前想知道的事

数据在哪里，模型由谁提供？

本地优先，是否意味着 AI 可以完全离线？

项目、对话、资料和笔记保存在本机。本地解析与本机 OCR 无需上传文档。教师对话、Ask AI、内容生成或可选云端识别，会将所需内容发送给你配置的服务。本地优先不等于模型离线运行。

软件和模型使用是否免费？

项目以 MIT 许可开源，内置示例无需 API。生成内容需要可用的模型连接，费用取决于你选择的服务商；项目不承诺免费模型额度。

它与“学习 AI 的课程”有什么区别？

Learn-With-AI 是帮助你学习不同学科的软件。你可以用它学习自动控制、数学或其他内容；本项目提供学习工作台，不是一个 AI 课程资源列表。

在哪里查看安装细节、源码和更新？

官方 GitHub 仓库包含安装与开发说明，Releases提供版本更新。遇到问题可提交 Issue。原仓库名为 LLL_life_long_learn，旧仓库链接继续跳转到当前项目。
